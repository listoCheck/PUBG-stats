# Map image sources

Paramo_Main.jpg and Miramar_Main.jpg were downloaded again from the original
8192 x 8192 PNG assets, without resizing, and encoded as JPEG quality 97,
with chroma subsampling disabled.

- https://github.com/pubg/api-assets/blob/master/Assets/Maps/Paramo_Main_High_Res.png
- https://github.com/pubg/api-assets/blob/master/Assets/Maps/Miramar_Main_High_Res.png

These are PUBG PC map assets from KRAFTON. PUBG Developer Terms apply.
The remaining WebP maps use the same official repository at 4096 x 4096.
