Жесты, дальность и точность высот

Касание — поставить выбранную точку. Перетаскивайте карту одним пальцем, масштабируйте двумя. Метки A и B можно перетаскивать.

Бирюзовая окружность вокруг A — максимальная номинальная дальность 700 м на одном уровне. Перепад высот меняет фактическую дальность.

Высоты определяются автоматически по картам рельефа сообщества (оценка, данные могут отличаться от текущей версии игры). Модель показывает поверхность земли, без зданий и мостов. Для Хейвена и тренировочного полигона данных нет. Настройка прицела вычисляется по приближённой модели сообщества и требует пристрелки; прямое расстояние показано отдельно.

Официальный PUBG API отдаёт телеметрию завершённых матчей. Ключ хранится только на сервере.
